# 微博发声人鉴别：基于 RoBERTa-wwm-ext-large 的分层用户类型分类

[**中文说明**](./README_zh.md) | [**English**](./README_en.md)

> 基于微博用户画像信息，构建细粒度用户类型分类模型。项目采用 **RoBERTa-wwm-ext-large** 进行预训练语言模型微调，并结合 **分层路由分类策略**、**类别重构** 与 **训练策略优化**，提升多类别文本分类任务的可分性与整体效果。

---

## 项目概览

本项目面向微博用户类型识别任务，利用微博用户的多维度信息对用户进行分类。  
原始任务包含 **24 个用户类别**，涵盖政府机构、媒体、学校、企事业单位、社会组织、自媒体、网民等多种类型。

项目的核心工作包括：

- 基于 **RoBERTa-wwm-ext-large** 的中文预训练语言模型微调
- 针对 **类别不均衡** 问题设计分阶段训练方案
- 基于 **特征空间可分性** 设计分层路由分类流程
- 通过 **标签清洗、输入标准化、规则剔除与多轮实验迭代** 持续优化模型表现

该项目不仅是一个文本分类实验，更体现了一个完整的 **算法工程问题拆解与建模优化过程**。

---

## 项目亮点

- **预训练模型微调**：采用哈工大讯飞联合实验室发布的 [RoBERTa-wwm-ext-large](https://github.com/ymcui/Chinese-BERT-wwm) 作为基础模型，完成中文用户分类任务建模。
- **分层分类架构**：不是直接进行一次性 22/24 分类，而是根据类别规模与类别间可分性构建多阶段路由分类流程。
- **标签体系优化**：剔除极低频标签，将原始 24 类重构为更适合建模的 22 类任务。
- **类别不均衡处理**：针对大类/小类样本规模差异，拆分训练集并分任务优化，降低头部类别对训练过程的干扰。
- **训练策略优化**：实验发现，文本统一长度处理能明显改善模型效果，体现了输入规范化对分类边界学习的重要性。
- **工程化实验迭代**：通过配置管理、阶段化模型保存与多轮实验对比，逐步定位影响准确率的关键因素。

## 方法设计

本项目没有直接使用“单模型一次性分类”的简单方案，而是根据数据特点对任务进行了工程化拆解。

### 1. 标签清洗与类别重构

在初始实验中发现，部分标签样本过少，容易对整体训练产生噪声。  
因此先通过规则剔除以下极低频类别：

- 明星红人
- 民主党派

将原始 **24 类任务** 调整为 **22 类任务**。

---

### 2. 训练集规模拆分：大类 / 小类

由于各类别样本量差异较大，直接训练会导致模型更偏向于优化整体准确率，而忽视少数类效果。  
因此，首先根据类别样本规模，将任务拆分为：

#### 大数据类别（12 类）

- 社区组织
- 党委
- 自媒体
- 网民
- 媒体
- 司法机关
- 学校
- 超话粉丝大咖
- 企事业单位
- 大V名人
- 社会组织
- 政府

#### 小数据类别（10 类）

- 基层组织
- 赛事活动
- 研究机构
- 检验检测
- 政协人大
- 演艺娱乐明星
- 公务员
- 行业专家
- 外国政府机构
- 国防军委

实验结果表明，**先按样本规模进行路由划分**，能明显改善后续分类表现。

## 关键工程经验

### 文本统一长度处理有效提升模型效果
实验表明，对输入文本进行统一长度处理后，模型分类效果有明显改善。  
这说明在当前任务下，输入规范化有助于模型学习更稳定的表示空间与分类边界。

### 类别不均衡不能只靠单次训练解决
对于长尾明显、多类别差异较大的任务，直接训练单个分类器往往无法兼顾整体与细粒度类别表现。  
更合理的方案是结合业务语义与数据分布，进行 **任务拆分 + 分层建模**。

### 分层路由比平铺式多分类更适合复杂标签体系
当类别数量较多且类间相似度差异明显时，先做粗分类，再逐步细分，是更接近工程实践的建模方式。
